### Running locally

```bash
pnpm install
pnpm db:generate
pnpm db:seed (optional)
pnpm dev
```

### About

Hypecult is an e-commerce platform built with [Next.js](https://nextjs.org), Prisma, and Stripe. It handles product listings, cart management, checkout flow, and order processing — including payment confirmation via Stripe webhooks and fulfillment sync with an external print-on-demand provider (Dimona).

> **This project is currently under construction.** Features and integrations are still being developed and may change significantly.
